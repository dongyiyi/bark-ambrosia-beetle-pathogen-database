# Contributing

Thank you for helping improve the Bark and Ambrosia Beetle Pathogen Database.

## What to report

Please use GitHub Issues for:

- suspected taxonomic errors;
- incorrect organism categories;
- duplicate or missing records;
- incorrect beetle-host associations;
- geographic metadata problems;
- incorrect evidence or validation coding;
- missing primary literature; or
- documentation problems.

## What to include

For record-level corrections, please provide as much of the following as possible:

1. the affected record or organism/host combination;
2. the relevant primary literature citation;
3. the current value you believe is incorrect;
4. the proposed correction; and
5. the evidence supporting the correction.

## Evidence standard

The database is literature-derived. Corrections should therefore be traceable to primary sources wherever possible. Taxonomic updates may also cite authoritative taxonomic sources.

## Scope note

The database distinguishes reported associations from experimentally demonstrated pathogenicity. Detection, isolation, or co-occurrence alone should not be interpreted as evidence of active infection, pathogenicity, or causation unless the source provides such evidence.

## Release policy

Accepted corrections will be incorporated into the working database and documented in subsequent public releases. The repository is currently in pre-release QA/QC; stable releases will be versioned and archived.
